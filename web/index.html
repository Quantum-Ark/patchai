Architecture Comparison

Why Verified Recovery Changes the Paradigm

Evaluating the differences between naive generative AI coding tools and PatchPilot's evidence-gated verification loop.

Capability / Dimension Naive AI Coding Tools (Copilot, Cursor, Sweep) PatchPilot AI (Verified Recovery)
Defect Confirmation Blind generation. Does not execute reproduction commands before editing code. Strict baseline reproduction. First proves the failure reproduces with non-zero exit code.
Regression Safety Silent failures. Frequently breaks existing logic while solving immediate issue. Dual-suite verification. Must pass both acceptance and comprehensive regression suite.
Rollback on Failure Leaves contaminated edits in the repository when tests fail. Atomic rollback. Instantly restores clean Git baseline and updates hypotheses.
Execution Guardrails Unbounded execution prompts or raw unchecked shell commands. Allow-listed command binaries, environment secret scrub, strict 60s timeout.
Telemetry & Audit Trail Opaque LLM chat logs with zero structured runtime metadata. Immutable Neatlogs HTTP traces, Entire session memory, and Crustdata enrichment.
Pull Request Promotion Claims completion purely because code syntax was emitted. Evidence-gated dossier. Never promotes without real command outputs and test execution proof.
Deterministic Control Plane

The 7-Stage State Machine

PatchPilot replaces hallucinating open loops with a formal finite state machine backed by SQLite checkpointing.

01

Intake

Parses GitHub issue URL or Markdown spec. Extracts stack traces and candidate file hints.

Input: Issue URL · Output: Issue Spec
02

Inspect

Clones disposable sandbox worktree, validates repository boundaries, records baseline Git SHA.

Tool: Entire Graph AST map
03

Reproduce

Executes targeted reproduction command in isolated subprocess. Confirms baseline defect exit code != 0.

Tool: TestRunner (Timeout 60s)
04

Patch

Generates minimal unified diff via configured LLM (OpenAI, Anthropic, Gemini). Validates syntax tree.

Tool: PatchTool (Backup Mirror)
05

Recovery

On test regression or syntax error, auto-rolls back to clean baseline SHA, categorizes failure, and replans.

Policy: RetryPolicy (Max 3 tries)
06

Verify

Executes both reproduction test AND complete test suite. Requires 100% exit code 0 confirmation.

Gate: Dual-Suite Acceptance
07

Report & PR

Compiles Markdown dossier with test logs, links Neatlogs trace ID, and opens audited GitHub Pull Request.

Output: PR Dossier + JSON Audit
